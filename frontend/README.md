# Bloomé — frontend

Angular 22 single-page application (standalone components, signals, reactive forms, SCSS).
See the [root README](../README.md) for setup, architecture and the full documentation.

```bash
npm install
npm start          # http://localhost:4200, proxies /api to http://localhost:8080
npm run test:ci    # unit tests (Vitest)
npm run lint       # ESLint (angular-eslint)
npm run build      # production build in dist/frontend
```
